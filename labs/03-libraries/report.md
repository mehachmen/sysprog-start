# ЛР 3. Библиотеки программы

Система: x64

## Библиотеки файла
Программа напечатала: libs.exe: sqrt(2) = 1.414214
Команда для списка библиотек файла: dumpbin /nologo /dependents libs.exe | findstr /i .dll
Библиотеки libs: KERNEL32.dll
Почему в списке нет отдельной математической библиотеки (или почему она есть): MSVC по умолчанию использует статическую компоновку, нужные части библиотеки C (printf, sqrt) скопированы прямо в libs.exe, поэтому отдельной библиотеки в списке нет. Динамически подключается только системная KERNEL32.dll
Где лежит интерпретатор Python (файл или библиотека): в библиотеке python3___.dll; сам python.exe - маленькая обертка, которая ее загружает
